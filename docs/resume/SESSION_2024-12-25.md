### ⏸️ Deferred Items

**Proprietary DNG Compression Support**
- **Issue:** Some DNG files (PhotometricInterpretation=32803) require 120+ seconds CPU processing
- **Root Cause:** LibRaw has no GPU acceleration; complex demosaicing on CPU only
- **Current Behavior:** Qt TIFF decoder fails → LibRaw processes full Bayer data → Very slow
- **Workaround:** Users should use corresponding JPG files
- **Future Solution Options:**
  1. Show embedded JPEG preview immediately, swap when full-res ready
  2. GPU-accelerated demosaicing (requires custom shader implementation)
  3. Caching pre-processed DNGs
- **Status:** Documented in FORMAT_COMPATIBILITY.md, marked as future enhancement
